# פסיכומטרי RPG

קורס אינטראקטיבי ומגומיין להכנה **למבחן הפסיכומטרי הדו-תחומי** (החל ממועד דצמבר 2026)
**ולמבחן אמירנט**. אפליקציית ווב סטטית, בעברית מלאה (RTL), ללא שרת וללא הרשמה —
ההתקדמות נשמרת בדפדפן.

```bash
npm install
npm run dev              # פיתוח
npm test                 # בדיקות יחידה
npm run validate:content # בדיקת תקינות מאגר השאלות
npm run build            # בנייה לפרודקשן
```

---

## למה שתי מסלולים

החל ממועד **דצמבר 2026** משתנה מבנה הבחינה הפסיכומטרית, לפי הודעת המרכז הארצי לבחינות
ולהערכה (מל״ל):

| | המבנה הקודם | **המבנה החדש — מה שהאפליקציה מכינה אליו** |
|---|---|---|
| תחומים | 3 (מילולי / כמותי / אנגלית) | **2 (מילולי / כמותי)** |
| מבנה | מטלת כתיבה + **8** פרקים | מטלת כתיבה + **5** פרקים |
| פרקים | 2 מילולי, 2 כמותי, 2 אנגלית, 2 פיילוט | **2 מילולי, 2 כמותי, 1 ניסיוני** |
| משך | כ-3.5 שעות | **כ-2.5 שעות** |
| שקלול | מילולי 40% / כמותי 40% / אנגלית 20% | **מילולי 50% / כמותי 50%** |
| אנגלית | בתוך המבחן | **הוצאה החוצה** → מבחן **אמירנט** נפרד |
| סולם | 200–800 | **200–800 (ללא שינוי)** |

שלוש מסקנות שמעצבות את כל האפליקציה:

1. **מילולי וכמותי עלו מ-40% ל-50% כל אחד.** כל נקודת שיפור בהם שווה עכשיו 25% יותר.
2. **אנגלית הפכה למבחן נפרד שאפשר לנצח בנפרד.** אמירנט הוא כיום המבחן היחיד שבודק
   אנגלית לצורך קבלה — נערך כל השנה ללא מועדים קבועים, וניתן לחזור עליו כל 35 יום.
3. **החיבור שווה יותר משנדמה.** מטלת הכתיבה היא רבע מציון המילולי, והמילולי הוא מחצית
   מהציון — כלומר החיבור לבדו נושא **כ-12.5% ממשקל הציון**, עבור 30 דקות של מיומנות
   שאפשר לאמן. זה יחס התשואה הטוב במבחן, ורוב הנבחנים העצמאיים מדלגים עליו.

בנוסף: עם שני פרקים בלבד לכל תחום, פרק אחד שאבד בגלל קצב עולה הרבה יותר מבעבר — ולכן
תרגול מתוזמן אינו רשות.

## מסלול א׳ — הפסיכומטרי

- **אבחון פתיחה** — מכייל את מנוע ההתאמה לכל נושא. המטרה אינה ציון.
- **מפת הכוחות** — נושאים כצמתים שנדלקים עם השליטה.
- **שיעורי טכניקה** — עד 7 דקות כל אחד, עם נוהל פעולה קבוע.
- **תרגול אדפטיבי** — דירוג יכולת בשיטת אלו, שאלות ברמה שמייצרת התקדמות.
- **קרב בוס** — פרק מתוזמן מלא. ניצחון דורש גם דיוק וגם עמידה בזמן.
- **סימולציה מלאה** — חמישה פרקים בסדר אקראי, בלי מחשבון, בלי לדעת איזה פרק ניסיוני.
- **מטלת כתיבה** — 30 דקות, ספירת שורות, ודירוג עצמי לפי רובריקה.
- **מרכז חזרה** — חזרה מרווחת ויומן טעויות מסווג.

## מסלול ב׳ — אמירנט

אמירנט החליף את אמי״ר ואמיר״ם במאי 2024, והוא **אינו גרסה מוקטנת של פרק האנגלית**:

- **הוא אדפטיבי לפי בלוק, לא לפי שאלה.** המבחן מגיש בלוק שלם ברמת קושי אחת, בודק אותו
  כיחידה, ולפי התוצאה קובע את רמת **הבלוק הבא**. אי אפשר לחזור אחורה.
- המשמעות המעשית: **דיוק בבלוקים הראשונים שווה יותר** מדיוק בסוף, כי הוא קובע על איזה
  סולם קושי יעבור שאר המבחן. לכן הסימולציה בנויה על מנוע נפרד (`src/engine/mst.ts`) —
  סימולציה שמתאימה את עצמה לפי שאלה הייתה מלמדת אסטרטגיה שגויה.
- **אוצר מילים משובץ בכל סוגי השאלות** ואינו נבדק בנפרד. לכן מאמן אוצר המילים הוא ההרגל
  היומי בעל התשואה הגבוהה ביותר במסלול.
- **מפת הניתוב** בסוף הסימולציה מראה לאיזה סולם הגעת ואיפה ירדת ממנו. אחוז דיוק שטוח
  לא יכול להראות את זה, וזו המשמעות האמיתית של הציון במבחן רב-שלבי.

**סולם הרמות (50–150):**

| ציון | סיווג | מה זה עולה |
|---|---|---|
| 134+ | **פטור** | אין קורסי אנגלית — **היעד** |
| 120–133 | מתקדמים ב׳ | קורס אחד |
| 100–119 | מתקדמים א׳ | כ-2 קורסים |
| 85–99 | בסיסי | כ-3 קורסים |
| 50–84 | טרום-בסיסי | 6–8 ש״ש לאורך שנה |

כל מוסד קובע ספים משלו — ניתן לעדכן את הסף בהגדרות.

## הדרך המהירה לעלות ציון

התוכנית נבנית אוטומטית מתאריך המבחן ומחלקת את הזמן לשלושה שלבים:

- **שלב א׳ (20% מהזמן) — הורדת טכניקות.** אבחון, ואז שיעורי טכניקה בלבד, כל שיעור עם
  תרגול יישום מיידי. רוב השיפור בפסיכומטרי מגיע מזיהוי ארכיטיפ והפעלת נוהל קבוע.
- **שלב ב׳ (40%) — תרגול אדפטיבי.** תרגול יומי בנושאים החלשים, וכל טעות נכנסת לחזרה
  מרווחת.
- **שלב ג׳ (השאר, לפחות שבוע) — סימולציה.** מבחנים מלאים בתנאי אמת ופרוטוקול סקירה.

**מסלול אמירנט רץ על לוח זמנים מוקדם משלו**: אימון אינטנסיבי בשבועות 1–4, ואז **גישה
למבחן האמיתי בסביבות שבוע 5**. ציון אמיתי שווה יותר מכל סימולציה והוא זול לחזרה. אם
עברת את הסף — המסלול נסגר וכל הזמן היומי עובר לפסיכומטרי, בדיוק כשהוא נכנס לשלב
הסימולציות. אם לא — נשאר מקום למחזור תיקון וחזרה למבחן.

## ארכיטקטורה

```
src/
  config/blueprint.ts      מבנה הפסיכומטרי — מקור אמת יחיד
  config/amirnet.ts        בלוקים, ניתוב, סולם רמות
  content/                 מאגר השאלות (JSON) + סכמות Zod
  engine/                  אלו, חזרה מרווחת, ניתוב MST, ניקוד, טקסונומיית טעויות, קצב, מתכנן
  screens/                 מסכי הפסיכומטרי
  screens/english/         מסכי אמירנט
```

**מספרי הפרקים והזמנים אינם מפורסמים על ידי המרכז הארצי** ומקורות ההכנה חלוקים לגביהם.
לכן כולם יושבים ב-`src/config/blueprint.ts` וב-`src/config/amirnet.ts` — כשיתפרסם המפרט
הסופי, תיקון שני הקבצים האלה הוא כל השינוי הנדרש.

## תוכן

כל השאלות **נכתבו במקור** בסגנון הבחינה. מבחני העבר של המרכז הארצי מוגנים בזכויות
יוצרים ואינם משוכפלים כאן — הם עדיין חומר התרגול הטוב ביותר שקיים, וכדאי לפתור אותם
מהאתר הרשמי במקביל.

הוספת שאלות: ראה [`docs/AUTHORING.md`](docs/AUTHORING.md). `npm run validate:content` בודק
סכמה, מזהים כפולים, כיסוי נושאים, ועומק מספיק בכל רמת קושי של אמירנט כדי שניתן יהיה
להרכיב בלוק מלא.

## פריסה

דחיפה ל-`main` מפעילה בנייה ופריסה ל-GitHub Pages
(`.github/workflows/deploy.yml`). יש להפעיל Pages עם מקור **GitHub Actions** בהגדרות
המאגר. אם שם המאגר שונה, יש לעדכן את `base` ב-`vite.config.ts`.

## מגבלות

- הציונים הם **הערכות למעקב התקדמות**, לא ציוני מרכז ארצי רשמיים. נוסחת ההשוואה של
  המל״ל אינה מפורסמת.
- ההתקדמות נשמרת בדפדפן אחד בלבד. יש כפתור ייצוא/ייבוא בהגדרות — השתמש בו לפני ניקוי
  היסטוריה או מעבר למכשיר.
